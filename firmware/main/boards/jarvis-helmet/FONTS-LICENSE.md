# Font licenses / Giấy phép font

Các file font LVGL trong thư mục này được sinh tự động bởi `tools/fonts/generate_fonts.py`
(lv_font_conv 1.5.3) từ các font dùng giấy phép SIL Open Font License 1.1. Dữ liệu bitmap
trong các file `.c` là bản chuyển đổi (Modified Version) của các font đó và được phân phối
theo cùng giấy phép bên dưới.

The LVGL font files in this directory are generated by `tools/fonts/generate_fonts.py`
(lv_font_conv 1.5.3) from fonts licensed under the SIL Open Font License 1.1. The bitmap data
in the `.c` files is a converted (Modified Version) of those fonts and is distributed under
the same license, reproduced below. None of the fonts declares a Reserved Font Name.
